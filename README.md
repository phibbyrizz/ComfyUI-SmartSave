# ComfyUI-SmartSave

Dynamic, LLM-powered output organization for ComfyUI. 
Analyzes generation prompts using a local LLM via Ollama and automatically routes finished images into structured subject folders with sequence indexing.

## Prerequisites

1. **Install Ollama**: Download from [ollama.com](https://ollama.com).
2. **Pull the default model**:
   ```bash
   ollama pull llama3.2:3b
```

## Example Workflow

An import-ready starter setup is provided in `examples/basic_workflow.json`. Drag and drop it directly onto the ComfyUI workspace to inspect the recommended wiring.
